# TimeMachine Cam: Android app

Point the camera, pick a time, and see the same place re-imagined by AI, from 500 million years ago to a million years from now.

**Install on an Android phone (Android 10 or later):** open this link on the phone, download the file and open it:

https://github.com/SantriGkioni/timemachine-cam-releases/releases/latest/download/TimeMachineCam.apk

Android asks to allow installing apps from your browser the first time. The app needs an invite code: ask the person who sent you the link.

**Updates:** in the app, Settings, "App", "Update". Android asks once to allow TimeMachine Cam to install updates, then each update needs one tap.

This repository holds only the released app files (and `latest.json`, which the app reads to find a new version). The pictures are made by AI and are imagined, not historical records.
